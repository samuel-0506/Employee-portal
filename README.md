# Employee Portal 🚀

A RESTful Employee Management System developed using Java, Spring Boot, Spring Data JPA, and MySQL.

## 🛠️ Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL
* Maven
* Swaggar

## ✨ Features

* Add a new employee
* Retrieve all employees
* Retrieve an employee by ID
* Update employee details
* Delete an employee
* Store employee data in a MySQL database

## 📂 Project Structure

* **model** — Employee entity
* **Controller** — REST API endpoints
* **Repo** — Database operations
* **Service** — Business logic
* **EmployeePortalApplication.java** — Main application class

## ⚙️ Database Configuration

1. Create a MySQL database named `sbdata`.
2. Configure the following environment variables:

   * `DB_USERNAME` — MySQL username
   * `DB_PASSWORD` — MySQL password
3. Ensure MySQL is running before starting the application.

## 🚀 How to Run

1. Clone this repository.
2. Open the project in Eclipse or another Java IDE.
3. Configure your database credentials.
4. Run `EmployeePortalApplication.java`.

Application URL: `http://localhost:9988`

## 🧪 API Testing

Use Postman to test the employee CRUD operations. Refer to `EmployeeController.java` for the exact endpoint URLs and HTTP methods.
